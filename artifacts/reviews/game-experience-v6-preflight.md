## 需要主动解决的冲突

1. **20题与原30幕**：新附件20题是设计示例，当前任务明确保留原30幕。入口、进度、报告档案、分享卡应全部统一30；约5分钟不宜作为未经实际试玩的保证。
2. **“没有标准答案”与理解力计分**：现实中的人没有统一答案，但游戏仍有作者设定心声。可表述“没有统一的异性答案”，同时交代分数为本局情境匹配；不能一面说无标准，一面不解释地给对错和准确率。
3. **“男性群体更可能”与没有群体样本**：换成普通人物、背影和物件不能凭空产生统计样本。报告仍评估本局另一性别人物的情境解读；不可宣称预测中国男性/女性群体。
4. **两性概括与单路线证据**：单局只看一种角色性别，不能写“男女都猜不准”或“理解两种性别的差异”。性别思维翻译器可解释为避免用性别套话、留意情境的解读风格，而非对两群体已验证的比较能力。
5. **解释式旁白不能回归**：杂志视觉可变轻，选择仍应猜具体内心话；不恢复每题“情绪支持/需要安全感”的学术选项、选后教学或AI聊天。

## 八指标可测性与分类规则

- 六能力应有逐题映射与分母：情绪洞察、动机判断、潜台词理解、行为预测、关系安全感、长期关系判断。解释为本局题目表现；其中行为预测实际依据何种线索/判断需写清，不能把动机题事后宣称为真实行为预测已验证。
- **性别刻板印象、自我投射不得从情感/安全感标签高频推算。** 当前单视角题无法测出这两项。须有实际可选择的归因表达，例如“因为男生一般会……”或“换我就会……”，才可统计显式归因选项。只统计选择记录，不能诊断真实偏见、自我认知或现实人格。缺乏有效题目时应显示证据不足，不补0。
- 普通型采用至少两个能力与实际预测倾向的复合匹配，避免最高单维直接命名。潜台词型关注潜台词+动机；侦探型关注行为+动机；现实主义关注长期+动机；安全感型关注安全感+沟通动机；共情关注情绪+关系；浪漫型要结合情感解读倾向；理性型结合实际问题解读倾向，而非假定低情感分就是理性。
- 三类特殊资格：观察家要求六能力整体较高且总分高；刻板印象型要求足量显式归因记录；直觉型要求真实有效计时与足够匹配表现。不能把快速乱选叫读心天才。
- 公布规则、同分处理和资格优先级。用可构造的30题答题记录验证12型都可达到，不仅给分类器随意塞人工分数向量。不合资格时在普通型间选最接近的复合路径，不能默认高分观察家。

## 真实计时的体验要求

计时从本幕选项可点击开始，累计前台可见时间，排除页面加载、动画/450ms防误触、切微信后台和恢复之前的时间。旧存档没有时间时记未知，不按0秒或快速作答判直觉型。使用足够多有效题的中位时间和匹配率，而非单题最快值。

“快”是本局观察，不等于心理学直觉能力；设备、阅读习惯和无障碍差异也影响速度。UI可轻量显示“已用时间”或相关记录，不必增加确认步骤或倒计时压力。

## 结果和传播内容

严格按用户要求：中文英文人格 → 理解分 → 最强能力 → 最大误区 → 错题型 → 隐藏属性 → 一句评价。八指标可用六能力雷达+两项归因提示，避免把偏见倾向与能力混在同一个“越高越好”的雷达里。

毒舌只能引用实际误读。全对不编“没事你真的相信”；单路线不说两性都不懂；别把称号写成永久人格或心理诊断。AI只润色固定人格、真实数据、真实代表错题，不能改类型/分数/事实或添恋爱经历；缺钥、失败、响应不合格时用同样完整可分享的证据模板。
