# 心动译码 · 可以玩的恋爱杂志

移动HTML单人情境测试：选路线 → 30个中国都市生活瞬间 → 点选直接进入下一幕 → 12型异性理解人格报告 → 分享。中途没有正误、解读、研究、确认按钮或AI对话。

## 运行与验证

```sh
npm start
# http://localhost:4173/
npm test
node scripts/qa.mjs
npm run build
node scripts/audit-v7.mjs
```

无需前端框架运行时。发布静态版本时只部署 `dist/` 到HTTPS；离线缓存包含全部运行模块。二维码库保留本地MIT许可。公开微信菜单分享仍需公众号签名和真机验收，本机不冒充公开部署。

## 内容与视觉

30个生活主题（原proposal第25题替换为生活杂事分工与搬家）、两套经历共60情境；男女各4位成年都市角色。男性初始走女生角色经历，女性走男生角色经历；重玩切换30幕经历，不按性别固定动机。第30幕不计分。

米白、黑、酒红的杂志版式，Serif标题与Sans正文，imagegen生成的8张Galgame二次元漫画板（封面＋7种生活氛围），大眼、简化五官、赛璐璐上色与人物／物件跨格；30题复用相应氛围板，具体事实由图下道具和聊天呈现。阶段背景从奶油色、淡玫瑰、灰紫回到明亮颜色；文字保持深色。场景用聊天与道具表达事实，避免解释角色心理。答案像没说出口的话；7幕预测行动和动机，8幕在同一次选择内附玩家判断依据。

## 固定人格资产

三组各4种展示类型，但分类跨多个特征比较，不能取最高单项：

| 情绪读取 | 动机理解 | 关系判断 |
| --- | --- | --- |
| 情绪雷达型 | 潜台词翻译官 | 安全感侦测器 |
| 共情型玩家 | 行为侦探 | 恋爱现实主义者 |
| 浪漫解码者 | 理性拆解者 | 性别刻板印象型 |
| 直觉型读心者 | 性别思维翻译器 | 异性观察家 |

`personality.js` 固定中文名、英文名、关键词、盲点提醒、一句话、复合分类器。`assessment-data.js` 管理题目→6项能力、两种明确归因依据、情境灵活度和浪漫场景的映射；新增内容沿用固定类型。12份真实30题答卷在 `tests/fixtures/personality.json`，全部可达，换选项位置不改分类。

六项能力：情绪洞察、动机判断、潜台词理解、行为预测、关系安全感、长期关系判断。按各自场景吻合题数／题数计算；题目可映射多个能力。三个核心轴分别取情绪+潜台词、动机+行为、安全感+长期的平均值。

两项隐藏归因：性别刻板印象、自我投射。仅计玩家选中的可见理由：以男生/女生泛化；因自己会如此就断定TA肯定一样。分母是实际经历的归因场景数，和正确率独立。普通换位思考、选情绪答案、猜错都不会自动计成偏见。它们是本局所选措辞的比例，不能诊断真实人格。

分类器版本 `12-types-v1`。常规9型用多项能力、动机倾向与归因特征组合比较；三种特殊资格：

- 刻板印象型：至少6幕有效归因场景，性别泛化理由比例≥50。
- 直觉型：至少20幕有效计时，8秒内比例≥70，剧情匹配分≥55。
- 观察家：匹配分≥85，三个核心轴均≥70，两种归因比例均≤25且归因样本至少6。

同时满足时按固定复合分和类型编号决胜；观察家是综合高分型，刻板印象型不是“坏人格”。优势引用真实能力数值，误区引用真实失配记录；没有失配不编错题，固定盲点明确是提醒。

## 计时与存档

`active-timer.js` 只累计可见、可作答时间。切题保护不计时，隐藏/pagehide保存累计，刷新恢复当前题已花时间。0–799ms或超过180秒的答题不进入节奏分类，防止程序连续点击或长时间挂起影响快型。快不等于理解得更好。

v7记录在 `heart-decoder-solo-v7`。旧v4/v6迁移保留路线、edition和其余选择；旧第25题答案及待提交选择作废，必须重答新情境。旧记录不会补造理由、行为预测或时间；旧键不删除。开始新一局替换当前v7记录，清理站点数据可删除本机记录。

## 报告与分享

结果包含固定中文/英文人格、理解力、三轴雷达（同时有数值文本）、最强能力、最大误区、最易失配题型、隐藏属性、全部8指标、一句话、30幕可展开完整档案和12型矩阵。研究背景只在档案与报告方法中出现。

PNG人格长卡750×1360，使用相同类型ID、名称、英文、分数和三轴数值。保存图片、原生分享降级、复制链接、公开地址二维码。好友从同一单人入口开始，不收到答案；链接只有 `?from=report`。微信JS-SDK默认不启用，配置 `wechat-signature-endpoint` 后由同源服务器签名，密钥留服务器。

## 可选AI报告润色

默认立即生成完整本地报告，不需要密钥或网络。`report-service.js` 使用 [OpenAI Responses结构化输出](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses)，服务器重新计算固定人格和事实，只允许AI写两段温和短评；页面的类型、分数、证据和固定一句话不可被替换。

可在运行服务器前配置服务器环境变量 `OPENAI_API_KEY` 与 `OPENAI_REPORT_MODEL`（使用账户可用的模型ID），再执行 `npm start`。服务器会将同源 `/api/report` 接入页面；静态部署默认仍使用本地报告，如需润色需单独部署此后端并设置 `report-narrative-endpoint`。客户端不持有密钥。响应错误、超时、错误类型或不合格文字自动保留本地报告，不阻塞报告和分享。当前验证包含真实HTTP调用到模拟供应方，不宣称已使用真实密钥调用供应方。

## 依据与边界

29道计分题的分数是与创作角色设定的吻合率，不是中国男女群体预测准确率，也不是验证过的心理量表。无真实群体答案比例；单视角不测性别信息前后效果，也不从答题推断现实人格。研究仅作背景，不证明角色选项或后续行动。

## v7回退与发布

每幕可回上一题，首幕可返回入口并续同一路线。回退保持seed、选项顺序、edition和后续选择；重新点击选择覆盖当前题，不追加重复记录。原选择轻标记，不揭示正误。报告可返回最后一题修改，最后一题提交后按最新答卷重算报告和分享图；旧AI文案不能覆盖新答卷。回看题和离开后再答的题不参与速度判定。

画稿由built-in imagegen按用户参考图生成，完整提示词在artwork/MANGA_V7_PROMPTS.md与MANGA_V7_PROMPTS_B.md。原PNG保留本机artwork/manga-v7，发布8张优化WebP共约1.7MB，所有画板进入离线缓存。

Cloudflare Workers静态资源配置：wrangler.jsonc，发布目录dist。先npm run build，再npx wrangler deploy。静态报告本地计算即完整可用；可选AI、微信SDK签名服务未启用时，不影响游戏、报告和保存分享卡。
